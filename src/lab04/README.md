# ЛР4 — Файлы: TXT/CSV и отчёт по частотам слов

Справка по готовому решению. Вывод команд и скриншоты — в [общем отчёте](../../README.md).

## Что сделано

>- `io_txt_csv.py` — ввод/вывод: `read_text` читает текст, `write_csv` пишет CSV,
>  `ensure_parent_dir` создаёт папку перед записью
>- `text_report.py` — скрипт: читает файл, считает частоты через `lib/text.py` из ЛР3,
>  пишет отчёт в CSV и печатает резюме в консоль
>- ввод/вывод и логика разделены: модуль ошибки только поднимает, показывает их пользователю скрипт

## Команды запуска

Все команды — из корня проекта `python_labs`.

| команда | читает | создаёт |
|-|-|-|
| `python3 src/lab04/text_report.py` | `data/lab04/input.txt` | `data/lab04/report.csv` |
| `python3 src/lab04/text_report.py --in A --out B` | файл `A` | файл `B` |
| `python3 src/lab04/text_report.py --in A --encoding cp1251` | файл `A` в cp1251 | отчёт в utf-8 |
| `python3 src/lab04/text_report.py --help` | — | — |

## Кодировки

>- вход читается в utf-8, другую кодировку передают флагом: `--encoding cp1251`
>- CSV-отчёт всегда пишется в utf-8, независимо от кодировки входа
>- если кодировка не подошла, скрипт печатает подсказку и выходит с кодом 1, а не трассировку

## Политика для пустого входа

>- в отчёт пишется только заголовок `word,count`
>- так файл остаётся валидным CSV и не ломает того, кто будет его читать
>- вариант «совсем пустой файл» отвергнут: заголовок ничего не стоит и понятнее читателю

## Если входного файла нет

>- печатается «Файл не найден» и подсказка про запуск из корня проекта
>- выход с кодом 1, чтобы в цепочке команд следующее звено не выполнялось

## Тест-кейсы

| № | вход | ожидаемый результат |
|-|-|-|
| A | `input.txt`: `Привет, мир! Привет!!!` | 3 слова, 2 уникальных; в CSV `привет,2` и `мир,1` |
| B | пустой `empty.txt` | 0 слов; в CSV только заголовок `word,count` |
| C | `input_cp1251.txt` в cp1251 + `--encoding cp1251` | 1 слово; в CSV `привет,1` |
